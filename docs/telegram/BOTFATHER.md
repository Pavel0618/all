# Создание бота Gem Radar — шпаргалка для @BotFather

Создать бота может только владелец аккаунта Telegram: это делается в переписке с [@BotFather](https://t.me/BotFather),
API для этого нет. Ниже всё, что нужно отправить. Каждое сообщение — просто скопируйте. Займёт около 5 минут.

**Перед началом:** сайт должен быть опубликован по адресу `https://pavel0618.github.io/all/`
(PR влит в `main` + Settings → Pages → Source: **GitHub Actions**). Картинки лежат рядом с этим файлом.

---

## 1. Создать бота

Отправьте в @BotFather по очереди:

```
/newbot
```
```
Gem Radar
```
Username — должен заканчиваться на `bot` и быть свободным. Попробуйте по порядку, пока не примет:
```
GemRadarApp_bot
```
```
XGemRadar_bot
```
```
GemRadarTrade_bot
```
BotFather пришлёт **токен** — сохраните его у себя и никому не пересылайте (для Mini App он не нужен).

## 2. Создать Mini App

```
/newapp
```
Выберите бота кнопкой, затем:

Название:
```
Gem Radar
```
Описание:
```
Находит мемкоины со всплеском хайпа в Twitter, проверяет по 5 шагам (хайп, кто раскачивает, контракт, график, нарратив) и покупает в 1 клик.
```
Фото 640×360 — отправьте файл **`miniapp-640x360.png`**.

GIF — пропустить:
```
/empty
```
URL:
```
https://pavel0618.github.io/all/
```
Короткое имя (часть ссылки):
```
radar
```
Готово: приложение открывается по ссылке `https://t.me/<username_бота>/radar`.

## 3. Кнопка «Открыть радар» в чате бота

```
/setmenubutton
```
Выберите бота, затем URL:
```
https://pavel0618.github.io/all/
```
Текст кнопки:
```
Открыть радар
```

## 4. Оформление профиля (по желанию)

Аватар:
```
/setuserpic
```
Выберите бота и отправьте **`bot-avatar-512.png`**.

Короткое «О боте» (видно в профиле):
```
/setabouttext
```
```
Радар X-гемов: хайп в Twitter → проверка контракта → покупка в 1 клик. Ключи только у вас.
```

Описание (видно в пустом чате до нажатия «Старт»):
```
/setdescription
```
```
📡 Gem Radar — поиск мемкоинов по методике «X-гемы через Twitter».

• Лента монет, у которых растёт интерес
• 5 проверок: хайп, кто раскачивает, контракт, график, нарратив
• Вердикт: входить или пропустить
• Покупка и продажа в 1 клик: Solana, Base, BNB, Ethereum, Arbitrum

Кошелёк создаётся прямо в Telegram, ключи хранятся только на вашем телефоне.

Нажмите «Открыть радар» внизу 👇

Не финансовый совет. Мемкоины — высокий риск.
```

## 5. Последний шаг — ссылки «Поделиться»

Сообщите разработчику username бота и короткое имя (`radar`) — или задайте сами в GitHub:
Settings → Secrets and variables → Actions → Variables → `TG_BOT` = username без @, `TG_APP` = `radar`,
затем Actions → Deploy to GitHub Pages → Run workflow.

## 6. Включить приём комиссии в SOL (один раз)

Откройте приложение → **Настройки → Комиссия сервиса → Создать счёт для комиссий** (≈0.002 SOL с
подключённого кошелька). Счёт для комиссий в SOL: `4R57Fw1hgcTVRrN4sVfXgzxsKzYRsHMWyHzvb51shzg8`
(wSOL-счёт адреса `GppeiwUj7jewiRqNmcH3YBMow9a3jCTLFf1dcY6F1bZx`). Комиссия в EVM-сетях начинает
приходить сразу, ничего создавать не нужно.
