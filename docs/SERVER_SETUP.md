# Автоматический режим: Twitter-анализ и бот с алертами

После настройки:

- **На сайте и в Mini App** шаги 1, 2 и 5 методики заполняются сами. Приложение показывает, сколько упоминаний за час и во сколько раз выросла активность, какие заметные аккаунты (KOL) пишут о монете, сколько среди авторов ботов и какие хэштеги в ходу. Открывать TweetScout, TwitterScore и Moni вручную больше не нужно. Кнопки на эти сервисы остаются для желающих перепроверить.
- **Бот сам присылает монеты.** Раз в 15 минут сервер проверяет одну сеть по кругу: находит монеты с ранним ростом, проверяет контракт, анализирует Twitter и шлёт сообщение, только если все 5 пунктов в порядке. Под сообщением кнопка «Открыть и купить» — она открывает Mini App сразу на этой монете.
- **Бот разбирает любую монету.** Пришлите ему адрес или ссылку — ответит вердиктом по 5 шагам.

Сервер — бесплатный Cloudflare Worker. Платить нужно только за данные Twitter.

## Что понадобится (≈15 минут)

| Что | Где | Цена |
|---|---|---|
| Ключ twitterapi.io | twitterapi.io | Оплата по факту: ≈$0.15 за 1000 твитов, одна проверка монеты ≈ $0.006. При лимите 120 проверок в сутки — не больше ≈$0.75 в день, на практике меньше за счёт кэша. Пополните баланс на $10 для старта. Цены по их документации — проверьте актуальные на сайте. |
| Аккаунт Cloudflare | dash.cloudflare.com | Бесплатно |
| Токен Telegram-бота | @BotFather | Бесплатно |

## Шаг 1. twitterapi.io

1. Зарегистрируйтесь на **twitterapi.io**.
2. Пополните баланс (например, на $10).
3. Скопируйте **API Key** в личном кабинете.

## Шаг 2. Cloudflare

1. Зарегистрируйтесь на **dash.cloudflare.com** (бесплатный план).
2. Откройте в меню **Workers & Pages** один раз — так Cloudflare создаст вам адрес вида `ваш-ник.workers.dev`.
3. Скопируйте **Account ID**: он на главной странице Workers & Pages, справа.
4. Создайте ключ доступа: аватар (справа вверху) → **My Profile** → **API Tokens** → **Create Token** → шаблон **Edit Cloudflare Workers** → **Use template** → **Continue to summary** → **Create Token**. Скопируйте токен (показывается один раз).

## Шаг 3. Telegram-бот

1. В Telegram откройте **@BotFather** → `/newbot` → имя `Gem Radar` → username, оканчивающийся на `bot` (например, `GemRadarApp_bot`).
2. Скопируйте **токен** вида `123456789:AA…`.

Остальное — кнопку «Открыть радар», команды, описание и вебхук — публикация настроит сама.

## Шаг 4. Вставить ключи в GitHub

Репозиторий → **Settings** → **Secrets and variables** → **Actions** → вкладка **Secrets** → **New repository secret**. Добавьте четыре секрета:

| Имя | Значение |
|---|---|
| `CLOUDFLARE_API_TOKEN` | токен из шага 2.4 |
| `CLOUDFLARE_ACCOUNT_ID` | Account ID из шага 2.3 |
| `TWITTERAPI_KEY` | ключ из шага 1 |
| `TELEGRAM_BOT_TOKEN` | токен бота из шага 3 |

## Шаг 5. Запустить

**Actions** → **Deploy** → **Run workflow** → **Run workflow**. Через 2–3 минуты:

- В логе шага «Check server» появится `{"ok":true,"twitter":true,"bot":true,…}`.
- Откройте бота в Telegram и нажмите **Старт** — алерты включены, внизу появится кнопка «Открыть радар».
- На сайте, на странице любой монеты, в шагах 1–2 появится «🐦 Автоматически по N твитам».

## Необязательные настройки

Там же, вкладка **Variables** (не Secrets). После изменения снова запустите **Run workflow**.

| Переменная | Что делает |
|---|---|
| `ALERT_CHAT_ID` | Слать алерты ещё и в канал: `@имя_канала` (бота нужно добавить в канал администратором). Для большой аудитории лучше канал: в личку бот рассылает максимум 20 подписчикам за раз. |
| `DAILY_TWITTER_BUDGET` | Сколько Twitter-проверок в сутки можно потратить. По умолчанию 120. |
| `TG_APP` | Короткое имя Mini App из `/newapp` (если создадите) — тогда ссылки «Поделиться» открывают приложение сразу, без чата бота. |

## Если что-то не работает

- **«Не удалось узнать адрес сервера».** Откройте Cloudflare → Workers & Pages один раз (шаг 2.2) и перезапустите.
- **В логах Cloudflare `Exceeded CPU`.** На бесплатном плане у сервера 10 мс процессора на запуск. Если сканеру не хватает, подключите Workers Paid за $5/мес — код менять не нужно.
- **«Лимит Twitter-анализа на сегодня исчерпан».** Поднимите `DAILY_TWITTER_BUDGET` или дождитесь следующих суток (по UTC).
- **Как проверить сервер.** Откройте `https://gem-radar.<ваш-ник>.workers.dev/health`.
