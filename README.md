# Gem Radar — торговля X-гемами по методике «через Twitter»

Веб-приложение и **Telegram Mini App** для обычных пользователей: находит монеты со всплеском интереса,
за минуту проводит их через 5 проверок методики «🧠 Как находить X-гемы через Twitter» и даёт купить или продать
в один клик — из своего кошелька (Phantom, Solflare, Backpack, MetaMask, Rabby…) на сайте или из встроенного
кошелька внутри Telegram.

- Без регистрации и без сервера: сайт статический, все данные хранятся только в браузере пользователя.
- Ключи не покидают кошелёк: приложение собирает сделку через агрегатор, а подписывает её сам пользователь.
- Работает на телефоне: откройте сайт во встроенном браузере Phantom или MetaMask, ссылки на это есть в окне подключения.

## Как методика превращена в приложение

| Шаг инструкции | Что делает приложение | Откуда данные |
|---|---|---|
| **1. Всплеск интереса** | Лента «Радар» с монетами, у которых растёт активность, и фильтром «под методику». Считает ускорение активности в пуле (сделки за 1 ч к среднему за 6 ч). Даёт ссылки на свежие твиты по тикеру, TwitterScore и TweetScout. | GeckoTerminal (тренды), DexScreener |
| **2. Кто раскачивает** | Находит Twitter проекта и одной кнопкой открывает карточку в Moni и Smart Followers в TwitterScore. Копирует ссылку на X для вставки в поиск Moni. Помечает токены, купившие рекламу на DexScreener («рекламные пуши»). | DexScreener (соцсети, boost) |
| **3. Безопасность** | Проверяет контракт автоматически: лок ликвидности, mint / pause / blacklist / whitelist, комиссии, прокси или скрытого владельца, honeypot. Если найдено хоть что-то опасное, вердикт «Не входить». | RugCheck + GoPlus (Solana), GoPlus (EVM, аналог TokenSniffer) |
| **4. График** | Проверяет капу (≤ $300–500k), ликвидность (≥ $20–30k), «зелёные палки», слив и давление продаж. Рисует свечной график (1 мин – 1 день, обновление раз в минуту) с линейкой для замера роста в %, как в TradingView, и даёт ссылку на GMGN (KOL и smart-кошельки). | DexScreener, свечи GeckoTerminal |
| **5. Нарратив** | Сверяет название и тикер со списком актуальных нарративов (AI, TRUMP, жабы и животные, ETF/L2, ICM). Список можно менять в настройках. | Ваш список |
| **Финальное решение** | Пять индикаторов и вердикт: «Можно входить», «Осторожно», «Пропустить» (2 из 5 слабые) или «Не входить» (опасный контракт). Если методика против покупки, кнопка разблокируется только после явного подтверждения риска. | — |
| **Покупка и фиксация** | Покупка и продажа (25 / 50 / 100%) прямо со страницы токена. Выбор slippage и приоритета. Портфель с ценой входа и иксами, подсказка «пора фиксировать» на ×2. | Jupiter (Solana), KyberSwap и резервный LI.FI (Ethereum, Base, BNB, Arbitrum, Robinhood) |

**Автоматический режим.** С подключённым сервером (Cloudflare Worker + twitterapi.io, см.
[`docs/SERVER_SETUP.md`](docs/SERVER_SETUP.md)) шаги 1, 2 и 5 заполняются сами: сервер читает свежие твиты
с адресом или $тикером и считает всплеск упоминаний за час, заметных авторов (KOL) и долю ботов, хэштеги.
Вручную открывать TweetScout, TwitterScore и Moni не нужно. Без сервера приложение открывает эти сервисы одной
кнопкой, а пользователь отвечает «Да» или «Нет». Ручной ответ всегда можно дать поверх автооценки.

**Бот с алертами.** Тот же сервер раз в 15 минут сканирует сети, прогоняет все 5 проверок и присылает в
Telegram только монеты с вердиктом «Можно входить», с кнопкой «Открыть и купить» в Mini App. Пришлите боту
адрес или ссылку — он разберёт любую монету.

**Сети:** Solana, Ethereum, Base, BNB Chain, Arbitrum и Robinhood Chain. Для Robinhood и для свежих токенов,
которых ещё нет в GoPlus, контракт проверяется по открытым данным Blockscout: открыт ли код, прокси ли
контракт, есть ли mint / pause / blacklist / смена налога, кто владелец, концентрация у держателей.

## Как пользоваться

1. Откройте сайт и нажмите «Подключить кошелёк».
2. Выберите монету в «Радаре» или вставьте в поиск адрес, ссылку (DexScreener, GMGN, pump.fun, Jupiter, X) или `$ТИКЕР`.
3. Пройдите шаги 1–5. Автоматические проверки уже заполнены, на остальные вопросы нужно нажать «Да» или «Нет».
4. Посмотрите вердикт, выберите сумму и нажмите «Купить», затем подтвердите сделку в кошельке.
5. Следите за позициями во вкладке «Портфель» и продавайте с той же страницы токена.

## Запуск и публикация

```bash
npm install
npm run dev        # локально: http://localhost:5173
npm test           # юнит-тесты логики методики
npm run e2e        # браузерный тест: лента, анализ, сделки, комиссия и Telegram Mini App на подменённых API
npm run build      # статический сайт в папке dist/
```

- **GitHub Pages.** Сайт публикуется workflow `.github/workflows/deploy.yml` при пуше в `main`. Один раз включите
  Settings → Pages → Source: **GitHub Actions**.
- **Vercel / Netlify / любой хостинг.** Загрузите содержимое `dist/`, настройки сервера не нужны.
- **Solana RPC.** По умолчанию используется публичный узел. Для стабильной работы получите бесплатный ключ у
  Helius или QuickNode и вставьте ссылку в «Настройки → Solana RPC».

## Telegram Mini App

Тот же сайт открывается внутри Telegram и сам переключается в режим Mini App: нативная кнопка «Назад»,
вибро-отклик на сделки, ссылки открываются во встроенном браузере Telegram, «Поделиться» отправляет токен в
любой чат ссылкой, которая открывает его проверку сразу в приложении.

**Кошелёк внутри Telegram.** Расширения Phantom и MetaMask в Telegram не работают, поэтому там есть встроенный
кошелёк. Пользователь нажимает «Создать», сохраняет показанные ключи (их можно импортировать в Phantom и
MetaMask) — и сразу может торговать на Solana, Base, Ethereum, BNB, Arbitrum и Robinhood. Ключи хранятся только на
устройстве: в защищённом хранилище телефона (Keychain / Keystore через `SecureStorage` Telegram), на
компьютере — в хранилище Telegram на устройстве. На сервер они не уходят. Есть импорт своего ключа, вывод
средств, показ ключей и удаление кошелька.

**Как запустить бота:** создайте его в [@BotFather](https://t.me/BotFather) командой `/newbot` и добавьте токен
секретом `TELEGRAM_BOT_TOKEN` — кнопку «Открыть радар», команды, описание и вебхук публикация настроит сама.
Пошагово: [`docs/SERVER_SETUP.md`](docs/SERVER_SETUP.md), картинки и необязательные шаги —
[`docs/telegram/BOTFATHER.md`](docs/telegram/BOTFATHER.md).

## Комиссия сервиса

С каждой сделки через приложение берётся комиссия на адреса владельца. Она показывается пользователю до
подтверждения («Комиссия сервиса 0,5% ≈ 0.0005 SOL») и уже учтена в сумме «Вы получите».

- **Solana**: платформенная комиссия Jupiter (`platformFeeBps`), всегда в SOL — и при покупке, и при продаже.
  Приходит на wSOL-счёт вашего адреса. Его нужно создать один раз: «Настройки → Комиссия сервиса → Создать счёт
  для комиссий» (≈0.002 SOL). Пока счёта нет, сделки идут без комиссии (ничего не ломается). В Phantom
  накопленное видно как Wrapped SOL; превратить в обычный SOL можно обменом wSOL → SOL в Jupiter. Jupiter может
  удерживать часть комиссии интегратора — актуальные условия смотрите на dev.jup.ag.
- **Ethereum / Base / BNB / Arbitrum / Robinhood**: комиссия KyberSwap (`feeAmount` в bps), всегда в ETH/BNB,
  сразу на ваш адрес. Если KyberSwap не нашёл маршрут и сделка идёт через резервный LI.FI, комиссия берётся
  только при заданной переменной `LIFI_INTEGRATOR` (имя интегратора в portal.li.fi), иначе такая сделка без комиссии.

**Сколько ставить.** По умолчанию 0,5% (`FEE_BPS=50`):

| Ставка | Кому подходит |
|---|---|
| 0,3% | Агрессивный рост: заметно дешевле всех, проще переманить пользователей ботов |
| **0,5% — рекомендую** | Вдвое дешевле популярных Telegram-ботов (Trojan, BonkBot, Maestro и т. п. берут около 1%), но заметный доход |
| 1% | Уровень рынка для ботов; оправдан, если есть сильное сообщество или эксклюзивные сигналы |

Пример: 300 сделок в день по $50 при 0,5% — около $75 в день. Комиссия ограничена 3% в коде на случай опечатки.

## Настройки владельца

Сейчас адреса для комиссии вписаны в `src/config.ts`. Поменять их можно там же или без правки кода — в GitHub:
Settings → Secrets and variables → Actions → **Variables** (переменные важнее значений в коде; для локального
запуска — файл `.env`, пример в `.env.example`):

| Переменная | Что это |
|---|---|
| `FEE_BPS` | Комиссия в базисных пунктах: 50 = 0,5% |
| `FEE_SOLANA_WALLET` | Ваш Solana-адрес для комиссии в SOL |
| `FEE_EVM_WALLET` | Ваш EVM-адрес (0x…) для комиссии в ETH/BNB |
| `TG_APP` | Короткое имя Mini App из `/newapp` (необязательно); username бота подставляется сам по токену |
| `LIFI_INTEGRATOR` | Имя интегратора в portal.li.fi — комиссия на сделках через резервный LI.FI (необязательно) |
| `ALERT_CHAT_ID`, `DAILY_TWITTER_BUDGET` | Канал для алертов и дневной лимит Twitter-проверок — см. docs/SERVER_SETUP.md |

После изменения переменных перезапустите деплой (Actions → Deploy to GitHub Pages → Run workflow).

## Устройство

```
src/lib/analysis.ts      5 критериев и вердикт (чистые функции, покрыты тестами)
src/lib/security.ts      RugCheck + GoPlus → 4 группы «что исключаем» из инструкции
src/lib/dexscreener.ts   цена, капа, ликвидность, соцсети
src/lib/gecko.ts         трендовые пулы и свечи для графика
src/lib/narratives.ts    нарративы и поиск совпадений
src/lib/jupiter.ts       обмен на Solana
src/lib/kyber.ts         обмен в EVM-сетях
src/lib/fees.ts          комиссия сервиса (Jupiter platform fee, KyberSwap fee)
src/lib/telegram.ts      Telegram Mini App: запуск, «Назад», вибро, диплинки, хранилища
src/lib/twitterSignals.ts  Twitter-сигналы шагов 1, 2, 5 (общий код сайта и сервера)
src/lib/blockscout.ts    своя проверка контракта по Blockscout (Robinhood, свежие токены)
src/lib/evmSwap.ts       обмен в EVM: KyberSwap → резервный LI.FI
src/config.ts            настройки владельца: комиссия, адреса, бот
src/wallet/              кошельки: Wallet Standard, EIP-6963 и встроенный кошелёк Telegram
worker/                  сервер (Cloudflare Worker): /signals, Telegram-бот, сканер алертов
src/components/          экраны: Радар, Токен (шаги 1–5), Покупка, Портфель, Методика, Настройки
```

## Риски

Мемкоины — экстремально рискованный актив. Автоматические проверки не ловят все виды скама, и это не
финансовый совет. Вкладывайте только ту сумму, которую готовы потерять.
